# Automatic Data Visualization Code Generation using Offline LLMs

## overview
This project, developed collaboratively, automatically generates data visualization code using offline Large Language Models.  
It analyzes datasets and produces suitable visualizations for better data understanding.

## Features
- Offline LLM integration
- Machine Learning integration
- Automatic chart/code generation
- Data analysis and visualization
- Python-based implementation

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Offline LLMs

How to Run-
1. Clone the Repository
2. Navigate to Project Folder
3. Create Virtual Environment
4. Activate Virtual Environment
5. Install Required Libraries
6. Run the Project
